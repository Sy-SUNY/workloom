先理解边界，再使用助手

产品要解决的问题

通用聊天框难以理解岗位差异、企业资料和个人工作习惯。Workloom 把角色、知识、指令、引用和反馈放进同一个员工工作空间。

两种运行方式

离线模式执行真实的权限过滤、词项检索、原文摘录、配置保存与记录持久化，不使用大模型。设置服务端模型环境变量后，切换为基于已检索资料的模型生成。

数据与权限

演示员工全部为虚构；每个岗位有独立个人资料与运行记录。演示角色由请求头选择，适合本地展示，不提供生产账号认证。不能把此服务直接当企业生产系统公开部署。

可演示的验证路径

① 选择现有岗位或创建自定义工作身份。
② 保存个人助手指令为新版本。
③ 提问并展开引用和运行链路。
④ 留下反馈，再人工调整指令。
⑤ 切换至测试工程师，确认个人文档和历史不可见。

工程说明

Python 标准库服务 + SQLite 持久化 + 原生网页。检索使用中文双字词 / 英文词项重合与分段，尚未使用向量数据库；反馈仅存储供人工审核，不声称自动学习。
